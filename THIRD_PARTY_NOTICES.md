# Third-party notices

This file lists the third-party libraries that Luaria embeds or uses to build, with their license texts. The project's own license is in `LICENSE` (MIT).

## What is redistributed

- **UI bundle** (`assets/ui/app.js`): CodeMirror 6, `@lezer/*` and dependencies (section 1).
- **Fonts** (`assets/ui/fontes/*.woff2`): IBM Plex and Space Grotesk, SIL OFL 1.1 (section 2).
- **Binaries** (`luaria`, `luaria-cli`, `luaria-gtk`): Rust crates listed in section 3.

## Not redistributed

- **Luau** (`luau-lang/luau`, MIT): `tools/luau.sh` clones and builds it; the repository does not contain the code. Text in section 4.
- **GTK4 and WebKitGTK 6.0**: system libraries, dynamically linked by the binaries; they are not copied into the repository. License LGPL-2.1+ (GTK4) and LGPL-2.0+ (WebKitGTK); the texts ship with the source packages.
- **esbuild** (MIT): build tool only (`npm run build`); it is not part of `app.js`.
- **UNC test** (`scripts/unc_check.lua`): downloaded on demand, never committed; see section 5.
